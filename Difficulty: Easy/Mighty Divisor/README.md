<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>

<strong>Output:</strong> 30
<strong>Explanation: </strong></span><span style="font-size: 18px;">30 is the smallest 2-digit number divisible by all three numbers.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a = 3, b = 5, c = 7, n = 2
<strong>Output:</strong> -1
<strong>Explanation:</strong> There is no 2-digit number divisible by all three numbers.</span></pre>

<h2><a href="https://www.geeksforgeeks.org/problems/pattern-jumping4855/1?page=2&category=Mathematics&difficulty=Basic&sortBy=submissions">Target with Jumps Equal to Positions</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an integer <strong>n</strong>, and a&nbsp;frog starts at position <strong>0</strong>.</span></p>
<ul>
<li><span style="font-size: 14pt;">In the first jump, it moves <strong>1</strong> unit forward.</span></li>
<li><span style="font-size: 14pt;">After that, if the frog is currently at position x, its next jump length is exactly <strong>x</strong> units.</span></li>
</ul>
<p><span style="font-size: 14pt;">Determine whether the frog can reach position n.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples :</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> n<strong> = </strong>3
<strong>Output: </strong>false
<strong>Explanation: </strong>The frog can't reach the position 3.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> n<strong> = </strong>2
<strong>Output: </strong>true
<strong>Explanation: </strong>The frog jumps from position 0 to 1 in its first jump. Since it is now at position 1, its next jump length is 1, taking it to position 2. Therefore, the frog can reach position 2.</span></pre>

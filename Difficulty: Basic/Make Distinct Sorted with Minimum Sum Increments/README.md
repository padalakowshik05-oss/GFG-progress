<h2><a href="https://www.geeksforgeeks.org/problems/making-elements-distinct3139/1?page=3&category=Mathematics&difficulty=Basic&sortBy=submissions">Make Distinct Sorted with Minimum Sum Increments</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p data-start="0" data-end="189">Given a sorted array <strong>arr</strong> of integers, make all elements distinct by only increasing their values while maintaining the sorted order. Find the minimum possible sum of the modified array.</p>
<p data-start="191" data-end="255" data-is-last-node="" data-is-only-node=""><strong>Note:</strong> After increasing the values, the array must remain sorted.</p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input :</strong> arr = {2, 2, 3, 5, 6}
<strong>Output :</strong> 20
<strong>Explanation: </strong>We make the array as {2, 3, 4, 5, 6}. Sum becomes 2 + 3 + 4 + 5 + 6 = 20
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input :</strong> arr = {20, 20} <strong>
Output :</strong>  41<br><strong>Explanation : </strong>We make the array as [20, 21]. Sum becomes 20 + 21 = 41.</span></pre>
